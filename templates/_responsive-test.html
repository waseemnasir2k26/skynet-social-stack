Responsive QA Matrix - social-stack v1.2.0

5 templates × 5 viewport widths = 25 cells. Hover any cell for amber outline.
HOW TO USE
1. Run `python -m http.server 8000` in templates/ folder
2. Open http://localhost:8000/_responsive-test.html
3. Visually scan grid - every cell must show the template legibly
4. Failures = template needs responsive contract fix
