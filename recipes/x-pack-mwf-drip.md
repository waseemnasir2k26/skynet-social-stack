# Recipe — X Pack (12 tweets, MWF drip)

X/Twitter does NOT use GHL. Native X scheduler or Hypefury. Plain text.

## Inputs

- Topic theme
- 12 tweets (default volume)
- Drip start, MWF cadence (3 weeks total)

## Tweet shape

- ≤ 240 chars
- Hook line 1
- Punch / specific in line 2
- Optional CTA in line 3
- Optional thread (1/n) for deeper

## Steps

### 1. Draft 12 tweets
- Mix: 4 punchy 1-liners / 4 mini-stories / 4 threaded teases
- Real claims only

### 2. Rank top 10
Drop bottom 2. Save the 10 ranked. (Top-10 ranking precedent: x-post-pack-apr22).

### 3. Build text drip file
```
2026-04-29 09:30 EST | tweet 1 text
2026-05-01 09:30 EST | tweet 2 text
...
```

12 tweets MWF = 4 weeks (Mon/Wed/Fri × 4 = 12).

### 4. Schedule via X native or Hypefury

### 5. Image variant (optional)
For "image tweets", use `templates/x-pack/index.html` → 1200×675 cards. Boosts impressions.

## No GHL

Reminder: do NOT add to GHL CSV. Native X scheduler.

## Engagement window

Reply to your own tweets w/ thread continuation 30-60 min after post.
