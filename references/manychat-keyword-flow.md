# ManyChat Keyword Flow

DM-keyword CTAs (e.g. "Comment GITHUB for the guide") need ManyChat wired BEFORE the post drips, or the funnel dies silently.

## The flow

```
Post → comment/DM with keyword → ManyChat triggers
  → reply 1: thank-you + link gate
  → reply 2 (after email): WA template send
  → tag in GHL CRM
  → optional: Calendly link
```

## Pre-launch checklist

- [ ] Keyword unique across IG / FB / WA flows (no collision)
- [ ] Auto-reply sequence drafted + tested
- [ ] WA template submitted to Meta (`github_guide_delivery`, `citelift_invite`, etc.)
- [ ] Meta soak window respected: **24-72 hours** before approval
- [ ] GHL tag-on-trigger wired
- [ ] First post Day 1 ≥ 72h after WA submit

## Per-platform wire

| Platform | Trigger | Notes |
|---|---|---|
| Instagram | Comment OR DM | DM more reliable, comment higher-funnel |
| Facebook | Comment on post | Slower than IG |
| WhatsApp | Direct message | Best conversion, Meta template gated |
| LinkedIn | Comment | No native ManyChat, manual follow-up |

## Common keywords (current list — check for collision)

- `JARVIS` — agency stack guide
- `GITHUB` — github funnel guide
- `CITELIFT` — early access (citelift.app)
- `N8N` — n8n setup script
- `ROSELYNE` — DO NOT USE on FB/IG (NDA-scrubbed)

Keep list updated when launching a new keyword.

## Failure modes

- ❌ WA template not approved → IG/FB triggers but WA arm dead → user thinks funnel broken
- ❌ Same keyword across two flows → ManyChat confused, picks wrong sequence
- ❌ GHL tag missing → user replies but never enters CRM nurture
- ❌ Manual LinkedIn arm forgotten → highest-intent comments lost

## Post-launch monitoring

- Day 1: check first 5 keyword hits manually
- Day 3: review DM throughput, flag dropoffs
- Day 7: weekly review — top sources, conversion %, dead branches
